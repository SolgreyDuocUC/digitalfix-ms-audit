# DigitalFix - Microservicio de Auditoría (ms-audit)

Microservicio encargado del consumo y registro de eventos de auditoría y timeline del sistema DigitalFix.

## Puerto

Puerto reservado para desarrollo local: `8087`, único dentro del ecosistema (ver la [tabla de puertos](https://github.com/SolgreyDuocUC/digitalfix-infrastructure#86-puertos-de-los-microservicios) en `digitalfix-infrastructure`). Al implementar el servicio, configurarlo con la variable `PORT` del `.env`.
